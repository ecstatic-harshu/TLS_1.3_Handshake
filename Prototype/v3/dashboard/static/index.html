Protocols

        
Hybrid stack used by this demo — classical TLS plus NIST PQC primitives.

      

      

        

          
TLS 1.3

          
Classical outer encrypted pipe. Provides the TLS contribution mixed into the hybrid key.

          Classical
        

        

          
ML-KEM-768

          
Post-quantum key encapsulation (Kyber family). Creates a shared secret resistant to quantum attacks.

          PQC
        

        

          
ML-DSA-65

          
Post-quantum digital signature (Dilithium family). Authenticates the peer over the handshake transcript.

          PQC
        

        

          
HKDF-SHA256

          
Combines classical TLS material + PQ shared secret into directional session keys.

          Hybrid
        

        

          
AES-256-GCM

          
Authenticated encryption for application payloads after the hybrid handshake completes.

          AEAD

          TLS 1.3 secret
          +
          ML-KEM-768
          →
          HKDF-SHA256
          →
          AES-256-GCM keys
